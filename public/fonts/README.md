# Typography — Ping AR + LT

| Style | Weight | Use |
|---|---|---|
| Regular | 400 | Body text |
| Medium | 500 | Labels, UI, small caps lines |
| Bold | 700 | Headlines, names |
| Extra Bold | 800 | Display / emphasis |

الخط مرخّص ومش مضمّن في الفولدر. حط ملفات الخط هنا (Regular / Medium / Bold / ExtraBold) وهيشتغل `fonts.css` تلقائي.
- ملفات SVG والـ HTML فيها نص حي بخط `Ping AR + LT`، وبيظهر بالخط لو منصّب على الجهاز، وإلا بيرجع لـ Arial / Noto Sans Arabic.
- قبل الطباعة النهائية: حوّل النص لـ outlines (Create Outlines في Illustrator / Convert to Path في Inkscape) عشان الخط يتثبّت.
- اللوجوهات نفسها paths، مش متأثرة بالخط.
